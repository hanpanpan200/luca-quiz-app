# 实物编程题库学习系统 · 设计文档

日期：2026-09-16
状态：已获用户批准

## 背景

Luca（小学三年级）备赛 26A02 未来之星AI挑战赛实物编程组。市赛第一阶段为线上答题资格赛（20 道单选 × 5 分，≥60 分晋级）。官方三套题库（基础版/进阶版/高阶版）是纯浏览页，答案直接可见，无法练习、检验、收集错题。

## 目标

一个最简单的本地学习系统：学习 → 练习 → 模拟考 → 错题改进闭环。

## 方案（已选定：纯静态单页应用）

- **架构**：1 个 `index.html`（原生 JS，无框架无构建）+ `questions.json`；学习记录存 localStorage；部署到 Vercel（静态）。不用 Supabase / 后端 / 登录。
- **使用设备**：家里 Mac 的浏览器（单设备，localStorage 足够；提供导出/导入 JSON 备份）。

## 数据

- `tools/extract.py` 解析 `raw/` 下 3 个官方题库 HTML → `questions.json`
- 字段：`bank`（基础/进阶/高阶）、`chapter`、`qno`、`text`、`options[4]`、`answer`（A-D）
- 清理：去除题干残留的 `N. ` 前缀
- 预期题量：基础 96 / 进阶 39 / 高阶 48（高阶含 1 道无答案题，标记 `needs_review: true`，不进练习/模拟考池，待家长确认后修补）
- 题目 ID = `{bank}-{chapter}-{qno}`

## 功能

1. **学习模式**：题库 → 章节逐题浏览，正确答案绿色高亮；`needs_review` 题显示"答案待确认"徽标
2. **练习模式**：按题库/章节刷题，点击即判对错并显示正确答案；答错自动进错题本
3. **模拟考**：三套题库混合随机 20 题 × 5 分；交卷出分，≥60 显示"晋级市赛现场赛"；错题入本；记录历史成绩（最近 N 次）
4. **错题本**：活跃错题列表 + 重刷模式；**连对 2 次自动毕业移出活跃列表**（保留历史计数）
5. **统计**：各章节正确率/已刷题数/活跃错题数；模拟考成绩走势
6. **备份**：设置区导出/导入 JSON（防清缓存丢数据）

## UI 要求（用户指定）

- 护眼配色：柔和米/浅绿底，低眩光；活泼风格（圆角卡片、emoji、渐变头饰）
- 大字体：正文 ≥18px，题干 ~22px，选项 ~20px
- 结构与操作简单：仅顶部 5 个 tab，无嵌套导航，单屏单任务

## 存储 schema（localStorage `swcode_quiz_v1`）

```json
{
  "answers": {"<qid>": {"right": 3, "wrong": 2, "lastResult": "wrong", "streak": 0}},
  "wrongBook": ["<qid>"],
  "examHistory": [{"date": "ISO", "score": 85, "total": 20}],
  "version": 1
}
```

- 答错 → 入 `wrongBook`（若不在），`streak` 清零
- 错题重刷连对 2 次 → 从 `wrongBook` 移出
- 普通练习答对不改变错题状态（只有重刷模式影响毕业）

## 测试

- `tools/extract.py` 配 pytest：题量断言、抽查题干/答案、无答案题标记、前缀清理
- 前端：本地起 http.server 手动验证四个模式 + 刷新后数据留存 + 导出导入

## 部署

Vercel 静态站（`npx vercel`）；Cloudflare Pages 为备选。

## 非目标（YAGNI）

- 不做账号/多用户/云同步；不做家长自建题库；不做移动端专项优化（Mac 优先，顺带响应式兜底）
