# 电子创芯赛训练模块 · 设计文档

> 日期：2026-09-28
> 状态：已与用户确认方案（声控计时为用户指定需求）
> 上游文档：`docs/电子创芯赛规则.md`（比赛规则拆解）

## 1. 背景与目标

Luca 参加 2026 杭州市科学与工程大赛电子创芯赛·电路创新设计子赛项：现场抽 4 题、限时完成电路拼装并演示。老师发了 60 道电路基础拼装题（1-3 年级版，`2024电路基础拼装(1-3年级）.pdf`），竞赛抽题大概率出自这 60 题。

**训练目标：每题 3 分钟内完成。**

本模块提供：原题+考点浏览、逐题计时练习、仿赛制模拟考、超时题反复练习。**App 不判电路对错**——效果核对由孩子对照实物演示自行负责，App 只负责计时与记录。

## 2. 数据资产

### 2.1 题目来源

- PDF 共 12 页、60 题，每题 = 文字描述（含填空）+ 电路图
- 嵌入图片 62 张（≈每题 1 张，多出 2 张待人工核对归属）

### 2.2 提取流水线（一次性）

1. `pdfimages -png` 提取全部图片到 `assets/circuits/`
2. 按 PDF 页内阅读顺序核对映射，重命名为 `q01.png ~ q60.png`（多出的 2 张丢弃或归并）
3. **映射验证**：渲染 PDF 页面为图（`pdftoppm`），与提取图人工抽查比对至少 6 题（每 10 题抽 1），防止题图错位
4. 题目文字从 PDF 文本层清洗（双栏乱序需按题号重组），校对填空括号完整

## 3. 页面结构

chip 屏内部 5 个 tab（复用现有 tabs 组件样式）：

| Tab | 内容 |
|---|---|
| 📖 学习 | 按考点分组浏览：电路图 + 原题文字 + 考点标签，不计时 |
| ✏️ 练习 | 选考点 → 组内随机逐题：电路图 + 题目 + 计时器（声控/按钮） |
| 🏆 模拟考 | 全 60 题随机抽 4 题，仿赛制逐题计时 |
| ⏰ 超时本 | 超时题列表，反复练习；连续 2 次 ≤3 分钟 → 毕业 |
| 📊 统计 | 各考点平均用时、超时率、毕业进度、模拟考历史 |

## 4. 计时与声控（核心交互）

### 4.1 状态机

```
idle ──(说"现在开始" / 点「开始」)──▶ timing ──(说"我做完了" / 点「✅ 完成」)──▶ done
 ▲                                                                              │
 └──────────────────(下一题 / 放弃不记录)───────────────────────────────────────┘
```

- **正计时显示**（mm:ss），**180 秒起数字变红**并标注「已超时」，不强制停止——孩子可以继续拼完，如实记录用时
- `done` 时记录：用时 ms、是否超时（>180s）；**超时 → 自动进超时本**
- 「放弃」不记录任何数据，回到 idle

### 4.2 语音控制（Web Speech API）

**定位：便利层，不是唯一入口。按钮永远同时可用。**

- `SpeechRecognition`（`webkitSpeechRecognition` 前缀兼容），`lang = "zh-CN"`，`continuous = true`，`interimResults = true`
- 仅在练习/模拟考的答题界面激活；离开页面停止识别
- **触发词**（对 interim + final 转写文本做子串匹配，反应快）：
  - 开始：`现在开始`、`开始计时`、`开始`
  - 结束：`我做完了`、`做完了`、`完成`、`结束`
  - idle 态只听开始词，timing 态只听结束词（避免读题误触发）
- 触发后 1.5 秒静默窗，防一句话重复触发
- `onend` 自动重启（浏览器静音即停的兜底），连续错误指数退避，最多 5 次后停止并提示改用按钮
- UI：🎤 状态角标——绿色=监听中、灰色=关闭、红色=不可用/权限被拒（附一句提示）

### 4.3 权限与降级

- 首次点 🎤 时请求麦克风权限；选择记忆在存储里
- 浏览器不支持（Firefox 等）/ 权限拒绝 / 识别持续失败 → 静默降级为纯按钮模式，页面顶部提示一次
- 语音识别由浏览器语音服务处理（Chrome 为云端服务），**孩子的话会被上传到浏览器厂商服务器**——文档明示此点，麦克风默认关闭、由孩子主动开启

## 5. 模拟考规则

- 从全部 60 题随机抽 4 题（贴近真实抽题，不做考点配额）
- 逐题计时（同 3 分钟标线、声控/按钮均可），一题完成自动进入下一题
- 交卷后成绩单：每题用时 + 超时标记 + 总用时；超时题自动进超时本
- 历史记录保留最近 20 场
- 无分数概念——竞赛排名规则是「完成数 + 用时」，成绩单直接呈现这两个量

## 6. 超时本与毕业

- 进入条件：任何一次用时 > 180s（练习或模拟考）
- 毕业条件：**连续 2 次 ≤ 180s** → 移出超时本（记录保留在统计里）
- 与 AI 模块「错题本」概念对齐，但数据完全隔离

独立 localStorage 键 `swcode_chip_v1`（与 `swcode_quiz_v1` 互不干扰）：

  "wrongBook": ["c18", "c22"],
  "graduated": ["c24"],

## 8. 错误处理

| 场景 | 行为 |
|---|---|
| `circuits.json` / 图片加载失败 | 显示「资产加载失败」卡片与重试按钮 |
| 某题图片缺失 | 学习/练习页显示占位图 + 题号，不阻塞其他题 |
| 语音不可用/权限拒绝 | 降级按钮模式 + 一次性提示 |
| 计时中途关闭页面 | 不记录该次（宁可漏记不可错记） |

## 9. 测试策略

延续现有 node 冒烟测试模式（stub 浏览器 API + vm 加载）：

- **计时状态机**（纯函数化）：idle→timing→done 转移、超时判定、放弃不记录、语音触发词与按钮走同一转移函数
- **语音模块**：mock `SpeechRecognition`，验证触发词匹配、静默窗、降级逻辑
- **数据完整性**：`circuits.json` 60 题、id 唯一、图片文件存在、考点 id 合法
- **模拟考抽样**：4 题不重复、多次抽样覆盖波动
- **超时本规则**：进本/毕业转移
- 现有测试（AI 模块 12 个 + Python 10 个）保持全绿

## 10. 非目标（本期不做）

- 不判定电路拼装对错、不维护标准答案库（孩子自核对）
- 不做答题进度云端同步（仅 localStorage）
- 不支持自定义触发词设置
- 不做倒计时模式
